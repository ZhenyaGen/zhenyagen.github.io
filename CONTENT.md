# Что нужно, чтобы заменить заглушки на реальные данные

Сейчас на сайте стоит текст, написанный по одному известному факту: вы
разрабатываете автоматизированные решения — и для своей организации, и для
внешних заказчиков. Всё остальное — обоснованные предположения, их нужно
подтвердить или заменить.

Можно просто ответить списком в свободной форме — оформление я возьму на себя.

## 1. Имя и позиционирование

- [ ] Как подписывать сайт: имя, имя и фамилия, никнейм?
- [ ] Как называете себя одной строкой: «разработчик автоматизации»,
      «инженер по интеграциям», «системный аналитик», иначе?
- [ ] Город и часовой пояс — указывать? (полезно для внешних заказчиков)
- [ ] Сколько лет в разработке / автоматизации?
- [ ] Фотография — есть? (если да, пришлите файл, добавлю на первый экран)

## 2. Стек — сейчас стоит предположение

В секции «Стек» перечислены типовые для автоматизации технологии. Нужно
оставить только реальные и добавить недостающие:

- [ ] Языки программирования
- [ ] Базы данных
- [ ] Платформы и системы, с которыми интегрируетесь
      (1С, Bitrix24, amoCRM, SAP, Jira, Google Workspace, что-то отраслевое)
- [ ] Инструменты автоматизации (n8n, Airflow, Power Automate, свои сервисы…)
- [ ] Инфраструктура (Docker, Kubernetes, облака, on-premise)
- [ ] Работаете ли с LLM / AI-агентами в автоматизации

## 3. Услуги

Сейчас перечислено шесть направлений: интеграции, автоматизация процессов,
внутренние сервисы, боты, отчётность, поддержка.

- [ ] Что убрать (не делаете или не хотите брать)?
- [ ] Что добавить?
- [ ] Есть ли направление, которое хочется вынести на первое место?

## 4. Кейсы — самое важное для продаж

Сейчас кейсов на сайте нет: выдумывать их нельзя. Даже 2–3 коротких примера
дадут сайту больше, чем весь остальной текст. Формат на каждый кейс:

- [ ] **Было:** как процесс работал раньше и чем это мешало
- [ ] **Сделал:** что именно построили
- [ ] **Стало:** результат — часы в неделю, сокращение срока, снижение ошибок,
      количество обрабатываемых заявок
- [ ] Можно ли называть заказчика, или писать обезличенно
      («производственная компания», «федеральная сеть»)

Если конкретные цифры под NDA — годится и обезличенная формулировка вроде
«ручная сверка на 6 часов в неделю ушла полностью».

## 5. Цифры для блока статистики

Блок с цифрами можно добавить на первый экран, если есть что показать:

- [ ] Лет опыта
- [ ] Реализованных проектов / внедрений
- [ ] Сэкономленных часов, обрабатываемых документов в месяц — любая метрика,
      которую готовы публиковать

## 7. Оффер («удочка»)

Сейчас: бесплатный 20-минутный разбор одного процесса.

- [ ] Годится или заменить? Альтернативы: бесплатный аудит на 1 час,
      чек-лист «что можно автоматизировать в вашем отделе» в обмен на контакт,
      бесплатный прототип для первой задачи, диагностика по вашему чек-листу.
- [ ] Есть ли ограничения по нагрузке (например, «2 разбора в неделю») —
      это хорошо работает как элемент дефицита.

## 8. Формат работы

- [ ] Берёте проекты как ИП / самозанятый / физлицо / через агентство?
- [ ] Формат: проект под ключ, почасовая работа, сопровождение по подписке?
- [ ] Есть ли ориентир по стоимости, который готовы публиковать?
- [ ] Языки работы: только русский или ещё английский (важно для Upwork/LinkedIn)?
