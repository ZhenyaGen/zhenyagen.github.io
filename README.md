# Евгений Тюрин — сайт-визитка

Одностраничный сайт. Никакой сборки и зависимостей — весь сайт лежит в
`index.html` и публикуется на GitHub Pages через GitHub Actions.

## Ссылка

**https://zhenyagen.github.io/**

Репозиторий называется так же, как адрес, — поэтому сайт открывается по
короткой ссылке, без хвоста с именем проекта. Если репозиторий
переименовать, короткий адрес перестанет работать.

## Как обновлять

Отредактируйте `index.html` и закоммитьте — публикация запускается сама и
занимает около минуты. Запустить вручную можно во вкладке **Actions** →
*Deploy site to GitHub Pages* → **Run workflow**.

Разметка разбита на секции: первый экран, услуги, «Кто я», история про
карточку лося, контакты. Картинки лежат в `img/`.

## Что стоит держать в голове

«Созвон на этой неделе · 2 места» на первом экране — живая цифра, её нужно
править руками, когда места закончатся.

Видео на сайте нет: чистого файла без водяных знаков ВК не нашлось. Если
появится, положите его в `video/hero-promo.mp4` и верните в скрипт подстановку
фонового ролика — она была удалена, но лежит в истории git.

## Что внутри

```
index.html                     весь сайт: разметка, стили и скрипт
img/                           фотографии и постер первого экрана
.github/workflows/deploy.yml   публикация на GitHub Pages
.nojekyll                      отключает обработку Jekyll
```

Шрифты подключаются с Google Fonts — единственная внешняя зависимость
страницы.

## Если публикация не работает

Проверьте, что в **Settings → Pages → Build and deployment → Source**
выбрано `GitHub Actions`. Токен Actions не имеет права включать Pages сам:
при выключенных Pages деплой падает с ошибкой
`Create Pages site failed: Resource not accessible by integration`.

Если ошибка касается `github-pages environment` и ветки — в
**Settings → Environments → github-pages → Deployment branches** разрешите
ветку, из которой идёт публикация.
