# Сайт-визитка

Одностраничный сайт-визитка. Никакой сборки и зависимостей — один файл `index.html`,
который публикуется на GitHub Pages через GitHub Actions.

## Ссылка на сайт

После первой успешной публикации сайт доступен по адресу:

**https://zhenyagen.github.io/ZhenyaGen/**

Если переименовать репозиторий в `zhenyagen.github.io`, адрес станет короче:
`https://zhenyagen.github.io/` — workflow при этом менять не нужно.

## Шаг, который нужно сделать руками (один раз)

**Откройте [Settings → Pages](../../settings/pages) и в блоке
*Build and deployment → Source* выберите `GitHub Actions`.**

Пока это не сделано, деплой падает с ошибкой
`Create Pages site failed: Resource not accessible by integration`. Это не
проблема workflow: токен GitHub Actions по соображениям безопасности не имеет
права сам включать Pages в репозитории — включить их может только владелец.

После включения зайдите во вкладку **Actions**, откройте workflow
*Deploy site to GitHub Pages* и нажмите **Run workflow** (либо просто сделайте
любой коммит — публикация запустится сама и займёт около минуты).

Если деплой падает с ошибкой про `github-pages environment` и ветку — в
**Settings → Environments → github-pages → Deployment branches** разрешите
нужную ветку.

## Как менять содержимое

Всё содержимое лежит в `index.html`. Места, которые стоит поправить под себя,
помечены комментариями вида:

```html
<!-- ═══ РЕДАКТИРОВАТЬ: ... ═══ -->
```

Основные точки:

| Что | Где искать в `index.html` |
|---|---|
| Имя, заголовок вкладки, описание для поиска | блок `<head>` в самом верху |
| Имя в шапке | `<a class="brand">` |
| Заголовок и текст первого экрана | секция `ПЕРВЫЙ ЭКРАН` |
| Услуги | секция `УСЛУГИ` |
| Этапы работы | секция `ПРОЦЕСС` |
| Технологии | секция `СТЕК` |
| Био | секция `ОБО МНЕ` |
| Бесплатное предложение | секция `ОФФЕР` |
| Соцсети и контакты | секция `КОНТАКТЫ` — лишние блоки закомментированы, раскомментируйте нужные |

Список данных, которые стоит подставить вместо заглушек, — в [`CONTENT.md`](CONTENT.md).

Любой коммит в ветку публикации автоматически обновляет сайт — обычно
это занимает около минуты.

## Что внутри

```
index.html                     весь сайт: разметка + стили, без внешних ресурсов
.github/workflows/deploy.yml   публикация на GitHub Pages
.nojekyll                      отключает обработку Jekyll
CONTENT.md                     чеклист данных для наполнения
```

Сайт адаптивный, поддерживает светлую и тёмную тему по системной настройке
и не загружает ничего со сторонних доменов — поэтому работает быстро и без
внешних зависимостей.
